# ADR-005: 使用 Lucide 本地静态 SVG

## Status: Accepted (2026-10-26)

## Background

项目需要统一功能图标，但不应为此引入 React、图标字体、运行时脚本或 CDN。Manifest V3 强调代码随扩展包分发，简单扩展最适合本地静态资源。团队规范要求锁定一套 SVG 图标库。

## Decision

锁定 `lucide-static@1.61.0` 为唯一图标来源，仅将使用的 SVG 复制到 `assets/icons`，保留许可声明。图标统一尺寸、stroke 和 `currentColor`；运行时不加载 Lucide JavaScript，不混用其他图标库或 emoji 功能图标。

## Consequences

正面：无运行时依赖、无远程资源、风格一致、打包体积小；原生 HTML 可直接使用。

负面：新增图标需从同一锁定包复制并维护许可；升级图标来源需要单独审查，不应全量无目的更新。
