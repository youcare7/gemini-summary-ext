# ADR-002: 使用 Interactions API 并固定响应契约

## Status: Accepted (2026-10-26)

## Background

项目没有已实现的 Gemini 请求，不能沿用交接文档中的模型和端点推断。官方当前将 Interactions API 推荐给新项目，`generateContent` 虽继续支持但已属 legacy。Interactions 在 2026 年 5 月将 `outputs` 改为 `steps`，并引入新的 `response_format`；默认 `store=true` 不符合本扩展最小数据保留目标。

## Decision

调用 `POST /v1beta/interactions`，Header 固定 `Api-Revision: 2026-05-20`，请求固定 `store=false`、`stream=false`。按 `steps -> model_output -> content -> text` 提取结果，使用 JSON 结构化输出并在客户端二次校验。当前项目子集写入 `docs/openapi.yaml`。

`gemini-3.8-flash` 仅作为有官方文档依据的候选默认模型；在项目真实推理成功前不标记为已验证，不自动降级或切换付费模型。

## Consequences

正面：采用新项目的官方主线接口；无状态请求减少服务端 Interaction 存储；固定 revision 与响应校验降低格式漂移风险。

负面：仍需跟踪官方 revision 和模型生命周期；`store=false` 不支持 `previous_interaction_id` 和后台执行；真实模型可用性仍受项目资格阻塞。
