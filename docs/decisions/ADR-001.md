# ADR-001: 在扩展 Service Worker 中直连 Gemini REST API

## Status: Accepted (2026-10-26)

## Background

当前扩展只有右键捕获和 popup Mock，尚无网络层。需要决定请求放在 popup、Service Worker 或自建后端。popup 会因失焦关闭；BYOK 若经过自建代理，会让第三方额外接触 Key 与网页正文，并产生运维成本。Chrome 官方允许声明主机权限后从扩展 Service Worker 发跨源请求。

## Decision

采用 Service Worker 内原生 `fetch` 直连 `https://generativelanguage.googleapis.com`。popup 通过 `chrome.runtime` 消息提交任务，Service Worker 统一处理 Key 读取、超时、取消、重试、响应校验和错误映射。Manifest 只新增该 Google 主机的权限，不建设后端。

## Consequences

正面：无服务器成本；请求不依赖 popup 存活；Key 和正文少经过一个接收方；网络逻辑可用 fake fetch 和 Playwright 独立测试。

负面：BYOK 仍位于用户浏览器，不能提供绝对保密；需要内部消息协议、会话任务状态和并发控制；跨源请求必须声明主机权限。
