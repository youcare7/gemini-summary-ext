# ADR-003: BYOK 默认使用会话存储

## Status: Accepted (2026-10-26)

## Background

用户要求自己提供 Key，且不得硬编码、提交或记录真实 Key。Chrome 官方指出 local 和 sync 未加密，不适合机密用户数据；session 将数据保存在内存并默认不向内容脚本暴露。当前代码还将选中文本持久写入 local 并打印到控制台。

## Decision

Key 默认只存 `chrome.storage.session`。用户主动勾选“记住 Key”并确认未加密风险后，才可写 `chrome.storage.local`；清除操作同时删除两个区域。正文和任务状态只放 session，sync 禁止保存 Key 与正文。local/session 均限制为 `TRUSTED_CONTEXTS`，删除正文日志和旧 `lastSelectedText`。

## Consequences

正面：默认减少落盘和跨设备扩散；清除语义明确；正文不再持久保存；满足最小权限和隐私目标。

负面：浏览器或扩展重载后通常需要重新输入 Key；可选持久化仍不是加密保险箱；用户本机恶意软件或高权限扩展不在本方案可防御范围内。
