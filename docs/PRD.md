## 1. 问题陈述

网页阅读者在遇到长文、陌生语言或可疑文案时，需要在“复制文本—切换工具—粘贴—判断结果”之间反复切换。通用 AI 侧边栏能缓解切换成本，但常见痛点是功能过重、额度与订阅规则难理解、聚合层故障以及数据流向不够直观。安全用户又容易把生成式回答误解为确定性的安全 verdict。

本项目真正要解决的不是“再做一个全能 AI 助手”，而是：**让用户对当前主动划选的一小段文本，以可控的数据边界完成摘要、辅助安全审查或中英翻译，并在失败时知道原因与下一步。**

现有替代方式及不足：

- 通用 AI 扩展：功能丰富，但对只需三种固定任务的用户偏重，通常引入账户、额度或订阅体系。
- 翻译扩展：翻译直接，但不覆盖摘要和风险解释。
- 安全扫描工具：擅长链接、文件和 IOC 检查，不等同于对整段社工话术做解释；用户仍需自行判断文本风险。
- 复制到聊天机器人：灵活，但上下文切换多、提示词不一致、数据去向和结果格式依赖用户手动控制。

## 2. 目标用户

### 主要用户画像

- 软件工程、网络安全方向的学生和初级开发者。
- 经常阅读中英文技术文章、公告、邮件或社区帖子。
- 能安装开发者模式扩展，但不一定熟悉复杂模型配置。
- 重视简单、直接、可检查的结果，不愿为低频使用维护另一套订阅。

### 次要用户画像

- 需要一个轻量开源示例来学习 Manifest V3、BYOK、提示词边界和错误处理的开发者。
- 需要快速初筛可疑文案的普通网页阅读者；产品只能辅助判断，不能替代安全产品或人工核验。

### 非目标用户

- 需要批量爬取、整站监控、团队管理、企业审计或自动阻断威胁的组织。
- 需要离线模型、多模型路由、图片/PDF/视频理解的创作者。
- 需要确定性恶意软件检测或专业漏洞验证的安全团队。

### 3.3 可实现的差异化

不是比模型数量，而是缩小任务与信任边界：

1. **单页三模式**：同一选中文本只提供摘要、安全审查、翻译，不做全能工作台。
2. **BYOK 无平台账户**：项目本身不代售额度、不经过自建中转；用户自行承担并管理官方 API 资格和费用。
3. **选中文本最小范围**：只处理用户主动选择并点击提交的文本，不读取浏览历史，不后台抓取整页。
4. **安全结果可核对**：安全审查必须列出“风险类型—原文依据—理由—不确定性—建议”，无依据时明确“不足以判断”，而非只给分数。
5. **失败也可信**：无 Key、无权限、限流、超时、异常响应均有可执行提示；模拟演示和真实 API 结果严格分标。
6. **公开证据优先**：README、真实演示、脱敏测试记录和 Release 与代码一致，不展示没有原始记录的数据。

## 4. 产品目标与成功标准

### MVP 目标

- 用户能从网页划词完成三种模式中的任意一种，并明确知道结果来自真实 API、明确标注的演示模式，还是失败。
- 新用户只读 README 即可安装、配置、执行固定样例和排查常见错误。
- 仓库、日志、截图、GIF、测试与 Release 中不出现真实 Key 或敏感选中文本。

### 验证指标，不设虚构目标值

- 功能：固定样例集中三种模式的通过率，以及每类错误是否被正确分类。
- 可复现：按 README 在干净浏览器环境完成安装与首次真实调用的步骤记录。
- 安全：密钥扫描结果、脱敏检查结果、权限清单与实际用途一致性。
- 反馈：仅发布真实试用的原始匿名记录；样本不足时只列个案，不推算比例。

## 6. MVP 范围

仅保留以下三个产品功能包；基础的结果复制、取消/重试和状态提示随功能包交付，不另开产品方向。

### 6.1 BYOK 与错误处理

- 首次使用显示设置入口和官方 API Key 获取说明链接；不要求创建本项目账户。
- Key 输入默认遮蔽，支持显示/隐藏、保存到本次浏览器会话、清除。
- MVP 默认不持久保存 Key；界面明确说明会话结束或浏览器退出后需重新填写。
- 请求只发往经官方文档确认的 Gemini API 端点，不经过项目方服务器或第三方中转。
- 缺少 Key 时不发送请求，提示去配置；失败不保留“分析完成”假象。
- 错误至少区分：未配置、认证失败、无权限/地区或项目不可用、限流/额度、网络离线、超时、响应格式异常、未知错误。
- 错误提示包含可理解的说明和下一步，不显示完整 Key，不输出含 Key 的请求头或日志。
- 官方能力未确认或用户项目无权限时，保留明确标识的离线演示入口，但不得将演示算作真实 API 测试通过。

### 6.2 划词三模式分析

共同流程：划选文本 → 右键进入扩展 → 查看选中内容 → 选择模式 → 主动点击分析 → 查看结果或错误。

- 摘要：默认 3–5 条要点；仅依据选中文本，不补造来源；内容不足时明确说明。
- 安全审查：输出风险类型、触发原文、判断理由、不确定性和安全下一步；只覆盖文本中的社工、钓鱼、凭据诱导、可疑链接/命令等风险提示，不做实时信誉查询。
- 翻译：MVP 仅中文与英文互译；默认自动识别方向，允许手动切换；专名、代码与数字不应无依据改写。
- 结果区显示当前模式、来源类型（真实 API 或离线演示）、时间与复制入口。
- 新请求会清楚标记旧结果已失效；请求期间禁止重复提交，可取消或等待超时后重试。
- 单次输入产品上限为 10,000 字符；超出时阻止发送并提示缩短，不静默截断。该上限是 MVP 产品限制，不代表模型实际上下文限制。

### 6.3 开源交付证据

- README：真实功能状态、权限说明、数据流、安装、BYOK、三种模式、固定样例、错误排查、限制、安全声明、测试方法。
- 演示：一段真实操作 GIF；真实 API 与离线演示分别标注，不混剪成虚假成功。
- 测试：公开、匿名、合法使用的固定样例；记录输入、模式、预期、实际、环境、日期与结果，失败也保留。
- Release：打包内容与对应代码一致；变更说明不声称未验证的浏览器、模型或地区支持。
- 密钥卫生：仓库与发布物扫描无真实 Key；GIF、截图、Issue 示例和测试日志均脱敏。

## 7. 明确不做项

以下均不进入 v1.0.0：

- 多模型、多供应商、模型价格比较或自动路由。
- 整页抓取、后台阅读所有网页、浏览历史同步、自动批量分析。
- PDF、图片 OCR、视频、语音、截图和文件上传。
- 对话式追问、自定义提示词、提示词市场、写作/改写、代码生成。
- 用户账户、云同步、历史记录、团队协作、订阅和支付。
- 持久保存 Key 的“记住我”；如后续增加，必须单独评估本机凭据风险。
- 自动访问选中 URL、实时 VirusTotal 查询、恶意文件扫描、漏洞验证、阻断或自动修复。
- “安全/恶意”二值保证、准确率宣传、风险评分排行榜。
- 跨区代理、绕过免费层限制、以绑卡作为项目安装条件。
- Edge、Firefox、Safari、移动端适配及国际化框架；仅保留文案外置可能性，不承诺支持。
- 紫色到粉色渐变、emoji 功能图标、空洞欢迎语或与核心流程无关的视觉装饰。

## 8. 验收标准

### 8.1 Given / When / Then

**首次配置**

- Given 用户未配置 Key，When 用户选择文本并点击分析，Then 不发送 API 请求，显示“需要配置 API Key”和设置入口，旧结果不被标为本次结果。
- Given 用户输入有效 Key，When 保存到会话，Then 界面只显示已配置状态，不回显完整 Key，源代码与日志不写入 Key。
- Given 用户已配置 Key，When 点击清除，Then 当前会话中的 Key 被移除，再次分析回到未配置状态。

**摘要**

- Given 已配置且 API 可用，选中文本为包含明确论点的文章，When 选择摘要并提交，Then 返回 3–5 条与原文一致的要点，结果标为真实 API。
- Given 选中文本信息不足，When 提交摘要，Then 输出“不足以形成可靠摘要”或同等明确提示，不补充原文没有的事实。

**安全审查**

- Given 选中文本包含“立即提供密码/验证码”等诱导，When 提交安全审查，Then 至少给出风险类型、对应原文片段、理由、不确定性和不泄露凭据的建议。
- Given 文本没有明显风险信号，When 提交安全审查，Then 结果说明“未发现明显文本风险信号，不代表链接、文件或发送者安全”，不得输出“绝对安全”。
- Given 文本只有 URL 且未做外部信誉查询，When 提交安全审查，Then 结果明确未验证域名信誉或实际落地页。

**翻译**

- Given 一段英文文本，When 选择中译英方向为自动并提交，Then 输出中文译文，保留原文中的数字与代码语义。
- Given 一段中文文本，When 手动选择中译英并提交，Then 输出英文译文，不额外附加摘要或安全建议。

**异常与演示**

- Given API 返回认证失败、无权限、限流或超时中的任一种，When 请求结束，Then 显示对应错误类别与下一步，不显示固定模拟结果。
- Given 用户主动进入离线演示，When 运行固定样例，Then 结果区持续显示“离线演示，非 Gemini API 结果”。
- Given 输入为空或超过 10,000 字符，When 点击提交，Then 本地阻止请求并显示具体原因。

### 8.2 EARS 验收建议

| 编号 | EARS 类型 | 需求语句 |
|---|---|---|
| E1 | Ubiquitous | 系统应始终区分真实 API 结果、离线演示结果和错误状态。 |
| E2 | Event-driven | 当用户提交有效选中文本时，系统应按当前模式向已核验的官方 Gemini API 发起一次请求。 |
| E3 | Event-driven | 当用户未配置 Key 时，系统应在发送请求前显示配置指引。 |
| E4 | State-driven | 当请求处于进行中时，系统应禁用重复提交并显示加载状态。 |
| E5 | Unwanted behavior | 如果 API 返回认证、权限、限流、超时或格式异常，则系统应显示分类错误与恢复建议，且不得展示为成功。 |
| E6 | Unwanted behavior | 如果输入为空或超过 10,000 字符，则系统应拒绝发送且不得静默截断。 |
| E7 | Optional feature | 当 API 不可用时，系统可提供明确标注的离线固定样例演示。 |
| E8 | Complex | 当安全审查未发现明显风险信号时，系统应同时提示文本审查的覆盖限制，不得作出绝对安全结论。 |
| E9 | Ubiquitous | 系统应在所有日志、错误、测试、演示和发布材料中避免记录或展示真实 API Key。 |
| E10 | Event-driven | 当用户清除 Key 时，系统应使后续请求立即回到未配置状态。 |

## 9. 边界条件

| 场景 | 产品行为 |
|---|---|
| 空文本、纯空白 | 禁止提交并提示重新划选 |
| 10,000 字符边界 | 等于上限可提交；超过上限本地拒绝；测试结果必须覆盖两者 |
| 特殊字符、HTML、Markdown、代码 | 作为文本处理；结果使用安全文本渲染，不执行选中内容 |
| 多语言混合 | 摘要按用户界面语言输出；翻译无法可靠判断方向时提示手动选择 |
| 选中文本含个人敏感信息 | 提交前提示只会发送当前选中文本；用户自行移除敏感内容；不自动上传其他页面内容 |
| 无网络、DNS 失败 | 显示网络错误和重试，不落入模拟成功 |
| 超时 | 30 秒后停止等待，允许重试；不得将超时请求记为成功 |
| 重复点击、快速切换模式 | 进行中只保留一个当前请求；旧结果明确失效，不拼接为本次结果 |
| 弹窗关闭后重开 | 可恢复当前会话配置与最后一次任务状态；若无法可靠恢复，明确提示重新提交 |
| 浏览器不支持自动打开弹窗 | 保留右键捕获，提示用户点击扩展图标继续，不阻断核心流程 |
| API 返回空内容或结构变化 | 显示响应异常和重试建议，不渲染空白成功卡片 |
| 并发/多标签页 | 每次任务绑定来源标签、选中文本和模式；不得把另一标签的结果当作当前结果 |
| 权限拒绝或 API 项目不可用 | 说明需检查官方项目、模型和地区支持；不提供跨区或绕限建议 |
| Key 清除/浏览器重启 | 会话 Key 不再可用；界面不得继续显示“已配置” |

## 10. 非功能需求

| 类别 | 要求 | 优先级 |
|---|---|---|
| 性能 | 常规本地环境下弹窗可交互时间目标小于 1 秒；操作反馈小于 300 毫秒；模型响应受网络与服务商影响，30 秒超时，不承诺未测 p95 | P0 |
| 可用性 | 所有核心状态有文字说明；API 失败不影响查看原文、修改模式、清除 Key 和运行离线演示 | P0 |
| 安全与隐私 | HTTPS；官方端点；输入校验；Key 默认会话级保存；不硬编码、不记日志、不上报分析平台；仅主动提交选中文本；安全审查含免责声明 | P0 |
| 权限 | 仅申请核心流程所需权限；README 逐项解释；不得为 MVP 增加浏览历史、下载、全站内容脚本等权限 | P0 |
| 兼容性 | 以当前稳定版 Chrome 的开发者模式实机验证；前一主版本仅在有真实环境时验证，未测环境明确标注 | P0 |
| 可访问性 | 键盘可达、可见焦点、文本对比度满足 WCAG 2.1 AA 基本要求；状态不只依赖颜色 | P1 |
| 可维护性 | 三种模式使用一致输入/输出契约；固定样例可重复执行；官方模型和端点变更集中在配置说明中更新 | P1 |
| 国际化 | v1.0.0 仅中文界面与中英翻译，不承诺其他语言；避免把文案硬编码为不可维护的分散字符串 | P2 |
| 图标与视觉 | 功能图标采用统一 SVG 图标库，具体选型由架构师锁定；无图标时使用文字；禁止 emoji 功能图标和紫粉渐变 | P1 |
| 数据验证 | 不发布无原始记录支持的性能、准确率、用户数、Star、社区参与或满意度数据 | P0 |

## 11. 数据埋点与验证方案

MVP 无账户、无支付、无后端，**不接入远程行为分析 SDK，不采集用户 ID、IP、原文、译文或 Key**。产品验证以公开测试记录和用户主动导出的脱敏诊断为主。

| 事件类别 | MVP 事件 | 用途与属性边界 |
|---|---|---|
| 获客/安装 | `extension_installed`、`readme_opened` | 仅本地记录是否发生与扩展版本；无远程上报 |
| 激活 | `key_configured`、`first_analysis_succeeded` | 只记录事件、模式、时间、版本；绝不包含 Key 或原文 |
| 核心使用 | `analysis_requested`、`analysis_succeeded`、`result_copied` | 仅模式、结果来源类型、耗时区间；不含选中文本 |
| 异常 | `analysis_failed`、`error_occurred` | 仅规范化错误类别、模式、版本；不上传原始响应或请求头 |
| 留存 | `session_started` | 仅本地会话计数，不生成跨设备或长期用户标识；不宣称 DAU/MAU |
| 转化 | 不适用 | 无注册和付费，不伪造 `payment_complete` 等事件 |

实现要求：

- 默认仅用于本地测试与故障诊断；用户主动导出前可查看并清除。
- 命名采用 `{对象}_{动作}`，属性仅含 `timestamp`、`extension_version`、`browser_version`、`mode`、`result_source`、`error_category` 中必要项。
- 不采集原文、Key、完整 URL、IP、精确位置、浏览器指纹。
- 发布后若需远程埋点，必须另做隐私评估、明示与 opt-in，不属于本 MVP。

## 12. 发布门槛

只有全部满足才可标记 v1.0.0：

1. 三种模式均至少有一条真实 API 成功记录；若官方资格仍阻塞，则版本只能标为演示/预发布，不得伪装完整 v1.0.0。
2. 六类以上错误路径有测试证据，且失败不会出现模拟成功结果。
3. BYOK 会话保存与清除通过测试，密钥扫描和人工脱敏检查无发现。
4. README 从干净环境可复现；权限、数据流、限制与安全边界完整。
5. 演示 GIF 与实际版本一致，真实 API 和离线演示分标。
6. Release 与代码一致，无未验证的模型、地区、浏览器和性能承诺。
